# CMP 170HX note (2026-09-11)

Stock: GA100 cut-down, 4480 CUDA, 8GB HBM2e, ~1493 GB/s, 250W, no display, PCIe Gen1 x4.
FP32 locked ~0.39 TFLOPS (1/32). Only fits 1.5B-7B Q4. Needs iGPU, Linux hacks.

Why #9 on Alibaba: one cheap listing lumps 30/40/50/90/170HX ($50-450, MOQ 1) vs MI100/MI300 ($3500+). Clicks, not datacenter buys. Spec table is keyword spam (DirectX 6, etc).

2025-2026 hype: community `cmpunlocker` (Falcon BootROM bug, nvidia-open 580.x/610) unlocks hidden HBM (8GB->64GB, 10GB->40/80GB) and FP32/FP16/Tensor (~164 TFLOPS FP16). Good for bandwidth-bound LLM inference (vLLM/llama.cpp) where A100 is banned.

Catches: volatile patch, Secure Boot off, pinned driver, no ECC, no NVLink, Gen3/4 fused off (x16 needs cap soldering), 56-70 SM vs 108 on A100 (~52-65% compute). VBIOS flash to A100 bricks.

Verdict: stock 8GB worse than used RTX 3090 24GB / 4060Ti 16GB for plug-and-play local AI. Unlocked 64GB only for tinkerers.
